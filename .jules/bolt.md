## 2024-10-27 - Node.js 파일 시스템 동기/비동기 성능 차이
**학습 내용:** fs.readFileSync와 fs.promises.readFile 간의 속도 차이를 벤치마킹한 결과, 작은 파일들을 읽는 동일한 작업에서 비동기 I/O (Promise.all) 방식이 동기(Sync) 루프보다 월등히 느린 성능을 보였다. (수십 배 느림). 대규모 I/O에서 이벤트 루프 스케줄링 오버헤드가 더 크며, 이런 특정 환경에서는 동기 단일 루프 처리가 더 나은 성능을 낸다. filter, map 체이닝으로 인한 배열 생성 비용도 단일 루프를 사용함으로 최적화 할 수 있었다.
**적용 계획:** 비동기로의 무분별한 리팩토링이 성능 향상을 보장하지 않음을 인지하고, 특정 I/O 작업 성능 향상을 위해서는 항상 동기와 비동기 작업 간의 벤치마킹 수행을 선행하여 실제 수치를 바탕으로 최적화 방식을 결정한다.
