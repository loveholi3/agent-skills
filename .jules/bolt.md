## 2026-09-01 - [스크립트 파일 단위 테스트 개선]
**학습 내용:** [require.main === module 패턴을 활용하여, 사이드 이펙트 없이 실행 가능한 스크립트 파일의 내부 함수들을 안전하게 단위 테스트에 노출(export)할 수 있음을 확인. Node.js 내장 모듈만을 사용하여 임시 디렉토리 및 파일을 통해 JSON 파일 I/O 로직 테스트 가능]
**적용 계획:** [향후 독립 실행형 스크립트 작성 시, 처음부터 로직과 실행부를 분리(require.main === module 체크)하여 작성하고, 로컬 함수들을 단위 테스트 파일로 추출(export/import)함으로써 코드 중복을 최소화하고 테스트 용이성을 향상시킬 것]
