## 2023-10-27 - 루프 내 Map 할당 최적화
**학습 내용:** 고빈도 루프 내에서 Map 인스턴스를 매번 새로 할당(O(N))하는 것보다, 루프 외부에 인스턴스를 선언하고 내부에서 `.clear()`를 호출하여 재사용하는 것이 가비지 컬렉션(GC) 오버헤드와 메모리 할당을 줄여 성능 최적화에 유리하다는 것을 확인했다.
**적용 계획:** 데이터 구조 재사용 패턴을 활용하여, 빈번한 루프 내 반복적인 인스턴스 생성 및 O(N) 탐색(`findIndex`)을 O(1) 해시맵 탐색으로 전환할 때 메모리 재사용 기법을 함께 적용한다.
