## 2024-05-24 - 동기 파일 읽기 병목 해결
**학습 내용:** Node.js에서 다수의 작은 파일을 다룰 때, Promise.all과 fs.promises를 활용한 병렬 비동기 I/O가 단일 스레드 블로킹을 해소하여 I/O 처리량이 증가함. 단순 마이크로 벤치마크에서는 Promise 오버헤드로 인해 동기 호출이 더 빠르게 측정될 수 있으나, 카탈로그가 커질수록 논블로킹 패턴이 확장성 측면에서 유리함. 단, Promise.all 맵핑 내에서 외부 배열을 .push()로 돌연변이시키면 경합 조건(순서 보장 안됨)이 발생하므로 반드시 반환된 배열을 필터링하는 함수형 패턴을 사용해야 함.
**적용 계획:** 파일 I/O나 비동기 데이터 로딩 최적화 작업 시, Promise.all 사용 후엔 외부 상태 변경(mutation) 대신 배열 리턴(순수 함수 패턴)을 사용하여 결정론적 결과를 유지할 것.
